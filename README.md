# VINASIG Organization Directory

This private repository stores the links, usernames, and contact addresses for VINASIG organization accounts.

See [ACCOUNTS.md](ACCOUNTS.md) for the account inventory.

## Scope and handling

- This directory records account references and contact identifiers only. Do not add passwords, recovery codes, API keys, or other authentication secrets.
- Entries reflect information supplied by the maintainer on 2026-09-27. Account ownership, access, and current availability have not been independently verified.
- The repeated PyPI entry in the supplied list is recorded once.
- The supplied Packagist URL ends at https://packagist.org/profile/ and contains no profile identifier, so no account URL is inferred.

## Updating the directory

When adding an account, include its platform, username or identifier, and profile URL or contact address. Review repository access before sharing this private repository.
